# NotasApp (HTML + CSS)

Proyecto pequeño que muestra una interfaz de notas hecha con HTML semántico y CSS nativo, sin frameworks.

Cómo probar

1. Abrir `index.html` en el navegador (doble clic o arrastrar al navegador).
2. Pulsar "+ Nueva nota" para abrir el modal de edición (CSS-only).

Notas

- No se ha añadido JavaScript todavía; el modal funciona con un checkbox oculto.
- El formulario es estático por ahora; más adelante podemos añadir interacción con JS.
